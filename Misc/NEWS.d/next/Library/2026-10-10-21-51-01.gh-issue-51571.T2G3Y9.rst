A file object from :meth:`socket.socket.makefile` whose buffered reader
keeps the data it read before a timeout (the :mod:`!_io._nibbler` one) now
lets reading go on after a :exc:`TimeoutError`, instead of failing every
later read with "cannot read from timed out object": nothing was lost, so a
read that timed out can be retried once more data arrives. Other file
objects still disallow it.
