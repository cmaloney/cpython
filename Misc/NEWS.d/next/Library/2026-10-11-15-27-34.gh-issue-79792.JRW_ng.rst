:meth:`io.TextIOWrapper.close` and :meth:`~io.TextIOWrapper.detach` now call
the incremental encoder with ``final=True`` and write what it returns, so
that an encoder holding input until it knows more, such as the ``idna``
codec's, no longer loses the end of the text (also :gh:`82666`). This is
done only when the encoder encoded text since it was created or reset, so a
reset encoder doesn't write a BOM.
